# Mount Lavinia dashboard ontology

This vault is the product map of the **live GitHub Pages dashboard** for the Galle Road corridor, Mount Lavinia. Open it in Ontology Atlas to see domains around the project.

Every `.md` file with `kind:` is a node. Frontmatter is the graph.

## What this vault covers

Shipped tabs: Overview, Focus Area, Movement and Behaviour, Land Cover Change, Environmental Analysis, Synthesis, Issues and Potentials, Export Maps, plus the evidence pipeline that prepares data and deploys the site.

## What it does not cover

Social media analysis, condo research, and park/site interventions are not on GitHub Pages and are not nodes here.
