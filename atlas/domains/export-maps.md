# Export Maps

Static map assets for reports: preview and download of prepared GeoJSON, rasters, and images.

## Includes

- Export Maps tab with sectioned download cards
- Preview of CRS and file type before download

## Excludes

- Interactive Leaflet analysis views
- Regenerating source GIS; exports consume already-prepared assets
